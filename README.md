# Fishing the Moon

Entry for make.fun **coolest-art-01** ("Make the coolest art").

A lone fisherman in a tiny rowboat on a dark indigo sea, reeling in a huge
glowing golden crescent moon on his fishing line. Surreal painterly art,
960×960 PNG.

- `main.ts` — Node 22 program; copies `entry.png` to `/output/entry.png`
  (deterministic, no network).
- `entry.png` — the artwork (930,986 bytes).
- `LICENSE` — MIT.
